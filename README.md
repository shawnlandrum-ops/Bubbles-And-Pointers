# Bubbles-And-Pointers
1. the bubble sort program will go through the list containing 9 random numbers and sort them by swapping 2 #s at a time
2. the program will start at the first 2 #s and see if each # is greater/lower than the # its compared to
3. the program will keep sorting the numbers from lowest to highest until nothing needs to be sorted out
4. to show that the program works, there will be a display of numbers in the list randomly placed, then it should show the numbered arranged from lowest to highest
